# Tài liệu dự án

Tài liệu kỹ thuật và quy trình dùng chung của Paw World Care được quản lý tại `doc/`.

| Thư mục | Nội dung |
| --- | --- |
| [source-code-management](source-code-management/README.md) | Gitflow, commit, review, quy ước đặt tên và cấu hình GitHub |
| `requirements/` | SRS, user stories, use cases, tiêu chí chấp nhận và truy vết yêu cầu |
| `architecture/` | Thiết kế tổng thể, sơ đồ thành phần và quyết định kiến trúc |
| `api/` | Hợp đồng API, OpenAPI và hướng dẫn tích hợp |
| `database/` | Thiết kế collections, quan hệ, indexes và từ điển dữ liệu |
| `ui-ux/` | Luồng màn hình, wireframe và tham chiếu thiết kế |
| `testing/` | Kế hoạch, test cases và báo cáo kiểm thử |
| `deployment/` | Hướng dẫn cài đặt, biến môi trường, triển khai và khôi phục |
| `meetings/` | Biên bản họp và quyết định của nhóm |
| [reports](reports/README.md) | Quy ước lưu các bản báo cáo được chọn để bàn giao |
| [references](references/README.md) | Danh mục tài liệu tham chiếu |

Tên thư mục dùng tiếng Anh dạng `kebab-case`; tài liệu có thể viết bằng tiếng Việt hoặc tiếng Anh theo đối tượng đọc. Tài liệu Markdown dùng tên mô tả rõ nội dung, ví dụ `booking-workflow.md`; biên bản họp dùng `YYYY-MM-DD-topic.md`.

Báo cáo chính thức tiếp tục quản lý trên Google Drive theo Report 2. Chỉ thêm bản xuất đã được nhóm chọn vào Git khi có yêu cầu; giữ phiên bản và lịch sử cập nhật của báo cáo. Không lưu dữ liệu khách hàng, thông tin truy cập hoặc secret trong tài liệu.
