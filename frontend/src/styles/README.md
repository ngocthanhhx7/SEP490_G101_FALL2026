# Shared styles

`workspaces.css` owns shared analysis plots, management tables, contextual forms
and row actions. Role shell and Customer account navigation remain in layouts.

Shared resets, tokens and site-wide styles belong here. `public-site.css` supplies public site/layout styles; `public-pages.css` supplies shared public page styling. Preserve stylesheet import order when moving CSS. Component-specific CSS may remain with its owning component/page, such as AvatarMenu or AdminUsersPage.

`catalog-layout.css` owns the shared service/product sidebar, two-column results and mobile stacking. Product photos retain the storefront containment rules.

`ai-models.css` styles the Admin AI lifecycle page, including bounded horizontal
table scrolling and responsive forms.
